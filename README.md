# Subojit Sarkar • Cybersecurity Explorer Portfolio

An ultra-premium, editorial cyber-tactical portfolio built to match the visual design with 3D WebGL animations and interactive security simulations.

## 🚀 Live Local Server
The development server is running at:
- **Local URL**: [http://localhost:5173](http://localhost:5173)

---

## 🛡️ Key Features & Structure

### 1. Header (Navbar)
- **Identity**: `SUBOJIT • CYBERSECURITY EXPLORER` with active pulsing emerald status.
- **Indexed Navigation**: `01 HOME`, `02 ABOUT`, `03 SKILLS`, `04 PROJECTS`, `05 LAB`, `06 JOURNEY`, `07 CONTACT` with scroll-spy synchronization.
- **Search Command Palette**: `CTRL + K` keyboard shortcut and search input triggering the command palette.
- **Audio Synthesis**: Non-intrusive tactical UI audio feedback synthesized with the Web Audio API (with one-click mute toggle).
- **CTA**: `LET'S CONNECT ->` pill button.

### 2. 01 HOME (Hero & 3D Threat Globe)
- **Brutalist Headline**: `I DON'T TRUST THE SYSTEM. I LEARN TO SECURE IT.` with deep tactical emerald accent (`#0e5a3c`) and decipher hover glitch.
- **Double-Exposure Avatar**: Subojit's portrait with digital holographic twin, matrix overlays, and `IDENTITY // 001` dossier tag.
- **Interactive 3D Three.js Global Threat Map**:
  - Dark cyber globe with glowing atmosphere.
  - Realistic landmass dot matrix.
  - Ballistic cyber attack arcs (Malicious crimson, Suspicious amber, Normal cyan) connecting world defense nodes.
  - Dynamic telemetry coordinates readout (`70.12`, `45.23`, `23.90`, `64.11`).
  - Interactive mouse drag to rotate in 3D.
- **Live System Status**: Network, Firewall, Intrusion Detection, and Cloud Services operational monitor.
- **Focus Progress**: Cybersecurity (85%), Cloud (70%), Web Dev (65%), Networking (75%).
- **3D Topographic Mesh**: Animated Three.js wireframe terrain strip.

### 3. 02 ABOUT (More Than Just Code)
- BCA student story with security research philosophy and recon/harden/evolve pillars.
- `MY FULL STORY ->` modal with competencies and certifications.
- Visual art card: Traveler facing misty peaks with *"SAME CURIOSITY. BIGGER GOALS."* signature.

### 4. 03 SKILLS (A Connected Learning Universe)
- Hexagonal constellation graph connecting `Cybersecurity`, `Networking`, `Programming`, `Linux`, and `Cloud`.
- Central rotating 3D wireframe polyhedron core with orbital rings (`SkillsCore3D`).
- Interactive skill selector displaying real-world toolchains, frameworks, and proficiency meters.

### 5. 04 PROJECTS (Real Problems. Real Learning.)
- Category filter pills: `ALL`, `CYBERSECURITY`, `CLOUD`, `WEB`, `TOOLS`.
- **Vulnerability Scanner**: Dark neon HUD preview with live simulated CLI audit modal.
- **Cloud Infrastructure**: AWS multi-tier VPC architecture with least-privilege IAM and WAF.
- Additional security tools (Network IDS, Zero-Trust Gateway).

### 6. 05 SECURITY LAB (Interactive Learning Space)
- **Visual Network Pipeline**: `Client` ➔ `Firewall` ➔ `Web Server` ➔ `Database`.
  - Real-time animated packet flow.
  - Interactive node inspector showing IP, packet headers, and filtering policies.
- **Simulated Attack Scenarios**:
  - `Port Scanning`
  - `Brute Force (Demo)`
  - `SQL Injection (Demo)`
  - `Traffic Analysis`
  - Streaming defense mitigation console showing real-time IDS alerts and counter-measures.

### 7. 06 MY JOURNEY (A Timeline of Growth)
- Interactive horizontal roadmap from 2021 to 2025.
- Clickable milestones detailing accomplishments from first scripts to professional security research.

### 8. 07 CONTACT (Let's Build Something Meaningful)
- Direct email address with instant one-click copy and clipboard toast.
- GitHub, LinkedIn, and Instagram links.
- "Send Encrypted Message" interactive modal with confetti celebration.
- Cryptographic PGP signature badge.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **3D WebGL**: Three.js
- **Styling**: Tailwind CSS (custom cyber palette & textures)
- **Icons**: Lucide React + custom inline SVGs
- **Audio**: Web Audio API oscillator synthesis
- **Celebration FX**: Canvas Confetti
